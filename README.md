# Kaora App (React + Vite)
Prototipe UI dengan layout topbar. Seluruh data adalah data simulasi.
```
npm install
npm run dev
```
Struktur: `src/data.js` (data & seri), `src/ui.jsx` (komponen & grafik SVG), `src/pages.jsx` (halaman), `src/App.jsx` (topbar & routing hash), `src/styles.css` (design system).
